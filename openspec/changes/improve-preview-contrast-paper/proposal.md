# 预览的真实对比度与古纸质感

## Why

当前预览的数字闸门虽然通过，浏览器实际呈现仍有两处余量不足：浅色方案的卡片说明与输入提示为 `4.648:1`，已经接近 `4.5:1` 下限；输入轮廓约为 `3.01:1`，在细边框和纸色面层上不够醒目。预览也仍是纯色圆角卡片，无法判断纸面层次，用户看不出古代书页、宣纸或印章的气质。

## What Changes

- 在生成阶段把普通辅助文字的推荐目标提高到 `5.5:1`，同时保留 WCAG 普通文字最低 `4.5:1` 的硬闸门；`bg` 与 `surface` 两个实际背景都要检查。若色库没有满足推荐目标的候选，交接报告明确显示实际比值与限制。
- 增加浏览器最终 CSS 选择器级别的检查，覆盖正文、说明文字、placeholder、卡片文字、按钮默认／悬停／按下、输入轮廓和焦点环；脚本结果与预览使用同一组 tokens。
- 将输入轮廓推荐目标提高到 `3.5:1`，最低合规线仍为 `3:1`，并让边框使用足够的实际线宽，避免数学上刚过但视觉上消失。
- 为 UI 预览增加可关闭的古纸层：纸纤维与轻微横向纹理只放在背景伪元素层，透明度受上限约束，`pointer-events: none`，不覆盖正文、按钮或输入框；同时增加页边装帧线和小型朱印，朱印计入已有 accent 面积预算。
- 交接文件新增纸张效果的使用说明、透明度上限、可读性禁用项和浏览器检查结果；不新增库外 hex，纹理只引用已经交付的 CSS 颜色变量。

## Impact

- 主要涉及 `scripts/engine.py`、`scripts/handoff.py`、`scripts/palette.py`、`scripts/selftest.py`、`assets/preview-ui.html`、`SKILL.md` 及相关交接与规则文档。
- 命令入口保持不变，526 色原始色库不改；新增的纸张层只影响 UI 预览与交接提示，不改变海报、服装和空间媒材的颜色选择。
- 本次变更保留已确认的三色和按钮色相方向，先修复实际配对余量，再添加低透明度装饰。

## Acceptance

- 默认素雅、青花、水墨和至少一个深色方案的浏览器实际选择器检查均通过；普通正文和辅助文字不低于 `4.5:1`，辅助文字优先达到 `5.5:1`，输入轮廓优先达到 `3.5:1`，焦点环与相邻页面／卡片背景不低于 `3:1`。
- 预览、CSS、交接 JSON 的前景／背景颜色完全一致；placeholder 和卡片说明不再只依赖脚本 token 配对而遗漏实际渲染层。
- 纸纹位于背景层，正文和控件可选中、可聚焦，窄屏无横向溢出；纸纹、页边、印章均使用现有变量，不出现任意新 hex。
- `python scripts/selftest.py`、OpenSpec 严格校验、Python 语法检查和 UTF-8 检查通过，并人工查看浅色、深色、窄屏和键盘焦点。
