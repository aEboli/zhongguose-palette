# 输出样例

模型对齐用。真实数字以脚本为准，不要抄下面的 hex 当记忆。

## 例 1：白话入口（最常见的一条路）

用户：「茶叶小店的网站，安静一点」

```bash
python scripts/palette.py ask "茶叶小店的网站，安静一点"
```

脚本先回读一行 `解读: 网页界面 · 素净耐看`，再给两套。照着念，按色条从长到短说：

```
第一套，最干净的一种：
  页面背景  粉白 #fbf2e3    约 78%
  卡片和导航  瓦松绿 #6e8b74  约 19%
  主按钮    苋菜红 #a61b29   约 3%
  正文用 长石灰 #363433，对比 11.2:1
  来处：粉墙上的竹影，与一角花窗
  当心：竹青铺成块的时候要把颜色压住，让它像影子而不像叶子
  别做：不要把苋菜红铺成整条顶栏，它只有 3% 的量

第二套换了个更冷的底（月白 + 战舰灰 + 淡茜红），红更柔。

要哪套？或者说「太素了」「红少一点」「改深色」我来调。
```

不要说「主场/结构/点缀」「氛围雅」「五行」「彩度」。不要报评分。

## 例 2：微调

用户：「太素了，再艳一点」

先读 `references/tweaks.md`，再跑：

```bash
python scripts/palette.py tweak "太素了，再艳一点" --mood 雅
```

脚本会打 `照做: 素艳 —— 雅 -> 艳`。转达时说人话：「往鲜亮那边走了一档」。

用户：「换个底，其他别动」

```bash
python scripts/palette.py tweak "换个底，其他别动" --from "鱼肚白+战舰灰+银朱" --keep secondary --keep accent
```

## 例 3：定妆并交给别的技能

用户：「就第一套」

```bash
python scripts/palette.py pick "鱼肚白+战舰灰+银朱" --scene 水墨 --media ui --pair-dark
```

写出 `.palette/handoff.json` 与 `.palette/palette.css`。转达时给六个槽和面积，
以及撞车提示（例如「这个白距通用暖奶油底很近，我们说明它是宣纸的白，
版式上要做出区别」）。细节见 `references/handoff.md`。

## 例 4：用户说了库里没有的色名

用户：「石青配月白的海报」

先 `python scripts/palette.py info 石青`，开头就说明：

> 石青不在这 526 色里。按它本义（蓝铜矿）对应库内的群青 `#1772b4`。
> 网上流传的那个薄荷绿不要用。

然后 `complete 月白 群青`，月白作底，群青成块或作那一点。

## 例 5：用户说「配个中国红的 App」

禁止输出「中国红」。`info 中国红` 会解析到朱红并给出话术。
直接给一套默认，不要先反问：

```
先按故宫那个气质给你一套：
  页面背景  汉白玉 #f8f4ed
  主按钮条和关键卡片  朱红 #ed5126   —— 不是整屏
  线脚和题名  姜黄 #e2c027         —— 不填面
  正文用长石灰，不要用朱红写长文（在纸色上对比不稳）
  别做：不要把朱红当页面背景；不要用紫荆红冒充朱红。
不满意的话，还有年画那种更热闹的，和水墨里只留一点朱的。
```

## 例 6：深色

用户：「做个后台仪表盘，深色模式」

`ask` 会走深底场景（石青地一枚金徽章），给出燕颔蓝/钢蓝一类的深底，
正文用银白 15:1 上下。不要把浅色方案反相，也不要用纯黑。

## 例 7：歧义（唯一值得追问的一种）

用户：「想要喜庆的红，但整体又要素雅一点，有水墨感」

脚本末尾会打 `歧义:响/静`。**先给两套素净的**，最后才问一句：

> 那个红是想铺开来一眼看见，还是只留一点点？

不要问「你要市井还是空灵」。用户不回答也已经拿到能用的方案了。
