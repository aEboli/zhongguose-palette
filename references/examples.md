# 输出样例

模型对齐用。真实数字以脚本为准，不要抄下面的 hex 当记忆。

## 例 1：用户说「给一个青花瓷网站配色」

先跑：

```bash
python scripts/palette.py generate --scene 青花 --n 3
```

再写成：

```
方案 1 · 93.9 · 清冷 / 青花 · 手选「青花甜白」
主场  雪白   #fffef9  白/金/无彩     整页纸地，甜白釉
结构  群青   #1772b4  青/木/中彩     导航、花纹、链接下划线
点缀  鷃蓝   #144a74  蓝/水/中彩     最深的钩线、当前页
建议像素面积  60≈80%  30≈16%  10≈4%
字色  长石灰  #363433  对比 12.3:1  AAA
为何这样配：永乐甜白釉上的苏麻离青。场是纸，青料勾花，深处用更暗的蓝压线。五行上近无彩的场不参与相克。
不要：加第四色（尤其不要红棕点缀）；不要把群青铺成整条顶栏。
CSS：
  --color-bg: #fffef9;          /* 雪白 */
  --color-secondary: #1772b4;   /* 群青 */
  --color-accent: #144a74;      /* 鷃蓝 */
  --color-text: #363433;        /* 长石灰 */
```

第二套若是算法方案（银白 / 睛蓝 / 海涛蓝），说明「比手选更淡、更当代，花纹用睛蓝而不是群青」。

## 例 2：用户说「石青配月白」

先跑 `python scripts/palette.py info 石青`，再 `complete 月白 群青`。

开头必须说明：「石青不在 526 色里。按蓝铜矿本义，本色库对应群青 #1772b4。网络上那个薄荷绿不要用。」然后给补全后的三色，月白作主场，群青作点缀或结构。

## 例 3：用户说「配个中国红的 App」

禁止输出「中国红」。问一句气质（宫廷艳 / 年画 / 水墨一点朱），同时先给一套默认：

```
方案 · 故宫气质（先用这个，不满意再换年画或水墨）
主场  汉白玉  #f8f4ed     页面背景
结构  朱红    #ed5126     主按钮条、关键卡片，不是整屏
点缀  姜黄    #e2c027     线脚、题名，不要填面
字色 长石灰，不要用朱红写长文（纸上对比不够稳）
不要：把朱红当 body 背景；不要用紫荆红/丹紫红冒充朱红。
```

## 例 4：用户给了两个色「乳白、银朱」

跑 `complete 乳白 银朱`。安静的乳白当 60，银朱当 10，脚本会补一个 30。交付时强调银朱的像素面积只有约 3–6%，并给字色。
