# 中国传统色文化

本文件处理色名、五行、禁忌和「用户说的那个色不在 526 里」的情况。
配色算法仍以 `colors.json` 的测量值为准；文化规则是语法，不是物理。

## 1. 两套色名，不要混用 hex

本技能的**唯一输出色库**是 [zhongguose.com](https://zhongguose.com/) 的 526 色（`references/source.json` → `colors.json`）。字段：name、pinyin、hex、RGB、CMYK。hex 是显示真源——有 8 条原始 RGB 与 hex 不一致（玫瑰灰最典型），一律以 hex 为准。

网络上另有一套约 161 色的文学色名（胭脂、玄色、石青、黛、竹青……），常见于 zerosoul/chinese-colors。用户会混着说。处理原则：

- 输出必须是 526 里的 target hex，禁止把文学色卡的 hex 交给用户。
- 文学 hex 只用来理解典故，并告诉用户「你说的石青在本色库叫群青」。
- 同名异色（粉红、朱红、月白等 16 条）同样以 526 为准。

`palette.py info 石青` 会打印别名原因、文学 hex 和库内目标。

## 2. 正色与间色

《周礼·考工记》画缋之事，杂五色。正色五：青、赤、黄、白、黑，对五方五行。间色是正色两两相加：

| 间色 | 出处（郑玄注） | 倾向 |
| --- | --- | --- |
| 绿 | 青之间 | 木 |
| 红 | 赤之间。古「红」≈今粉红、桃红，古「朱」才是正红，「绛」比赤更深 | 火 |
| 碧 | 白之间 | 金/木 |
| 紫 | 黑之间 | 水或火 |
| 缁 | 黄之间 | 土/水 |

**恶紫夺朱**：不要让响亮的间色当主场。求「雅」而非「正」的场合（文人、江南、闺阁）可以反过来以间色为主。

先定五色正轴，再取具体色名。正色是结构，色名是该结构上的采样点。禁止输出泛称「中国红」，落到朱红、银朱、苋菜红、鹤顶红、枫叶红。

库内 122 个「红」字色是现代语义。引用古文献时，「红」不要自动映射到银朱。

## 3. 五行：相生为和，相克为冲

| 行 | 正色 | 方位 | 季节 | 本技能的色系归入 |
| --- | --- | --- | --- | --- |
| 木 | 青 | 东 | 春 | 青、绿、偏浅的蓝 |
| 火 | 赤 | 南 | 夏 | 红、粉、高彩橙 |
| 土 | 黄 | 中 | 长夏 | 黄、棕、低彩橙 |
| 金 | 白 | 西 | 秋 | 白、浅灰 |
| 水 | 黑 | 北 | 冬 | 黑、深灰、深蓝、深紫 |

相生（和）：木→火→土→金→水→木。
相克（冲）：木克土、土克水、水克火、火克金、金克木。

用法：给配色一个「古人认可的搭配理由」，不是迷信。同色相生加分，相克减分。**近无彩的场（纸、绢、宣、素墙）不参与相克**——否则甜白釉配青花会因「金克木」被误伤，而那恰是中国最经典的配色。点缀相克其实常见（朱印钤在墨上），减分很轻。市井、浓烈、年画允许相克，还可能加分。

祭祀与医学的五脏对应不同，本技能不使用五脏，只使用方位与季节作为检索标签。

## 4. 「青」是最大的模糊区

按字面筛「青」在 526 里只有 9 条，实际青轴覆盖蓝、绿、灰蓝、近黑、甚至紫：

| 名字 | 实测 | 归入 |
| --- | --- | --- |
| 花青、群青、靛青 | h≈250–280°，蓝 | 青/蓝，木或水 |
| 碧青、海青、虾壳青 | 青绿 | 青/绿，木 |
| 青莲 | h≈340° | 紫 |
| 钢青 | L\*≈13 | 近黑，水 |
| 鲛青 | 实测偏暖绿褐 | 名义仍是青 |

teal 仍属木，不因色相把青改归水。用户说「青」时先问是青花的青（蓝）、竹青的青（灰绿），还是青莲的青（紫），再解析。

## 5. 色名以物，望文会生义

526 色几乎全部以物命名。来源决定语境：矿物色可作重彩大面积，草木色宜作素雅底子，禽羽色多为点缀。

不能望文生义的条目（选色按 LCh，不按字面）：

| 色名 | 实测 | 易误读成 |
| --- | --- | --- |
| 海参灰 | 近白 `#fffefa`，L\*=99.6 | 深灰 |
| 长石灰 | 近黑 `#363433` | 浅灰 |
| 新禾绿、橄榄绿 | h≈95°，实为黄 | 绿 |
| 栗紫、酱紫 | h≈350°，酒赤 | 紫 |
| 马鞭草紫、淡藤萝紫 | C≈4，实为粉白 | 紫 |
| 苷蓝绿、槲寄生绿 | C≈4，实为近黑 | 绿 |
| 莲子白 | C=23 的奶油，仍是白 | 黄 |

分类原则：**色名优先于色值**。名叫白/灰的，只有实测彩度极高（C≥35）才改判。名叫彩色但实测近无彩（C<5）才改判为白/灰/黑。

## 6. 别名表：用户常说、库里没有

完整表在 `references/aliases.json`（140 条 + 16 条同名异色）。下面是必须文化校正、不能只按色差最近邻的条目：

| 用户说 | 库内目标 | 为什么不能按网络 hex |
| --- | --- | --- |
| 石青 | 群青 `#1772b4` | 石青是蓝铜矿，正色深蓝。网络色卡常给薄荷绿 |
| 天青 | 霁青 `#63bbd0` | 汝窑「雨过天青云破处」，青中带灰，不是鲜蓝 |
| 玄色 | 可可棕 `#652b1c` | 玄是赤黑，黑中带红，周礼正色 |
| 胭脂 | 苋菜红 `#a61b29` | 红花染出的暗红，国画颜料 |
| 竹青 | 瓦松绿 `#6e8b74` | 竹皮的灰绿，不是鲜绿 |
| 黛 | 野葡萄紫 `#302f4b` | 青黑色画眉颜料，不是鲜紫 |
| 漆黑 | 燕颔蓝 `#131824` | 526 无纯黑，这是最接近的极深色 |
| 墨色 | 战舰灰 `#495c69` | 墨在水墨里是蓝灰，不是纯黑 |

| 靛蓝 / 藏青 | 鷃蓝 `#144a74` | 菘蓝染出的深青蓝，近黑 |

## 7. 禁忌只作脚注，不作阻断

- **明黄**：隋唐以降帝室专用。作脚注，用户明确要宫廷黄时仍给姜黄、甘草黄，但不要当主场铺满。
- **琉璃瓦分级**：黄用于帝王宫殿陵庙，绿用于王府，青用于祭祀（天坛象天），黑紫用于园林。场景「故宫」用黄作点缀线脚，不是满屏黄瓦。
- **白**：纯白关联丧仪素服；月白、雪白、象牙白、鱼肚白是雅色。用后者，不用精白充丧。
- **紫**：中国为祥瑞权贵（紫禁城取紫微垣），与西方「忏悔/奢侈」不同；同时《论语》「红紫不以为亵服」表明它作为间色曾被视为乱正色。尊贵与逾制两义并存，脚注即可。
- **紫禁城红墙黄瓦**是礼制建筑特例，禁止直接当 App 模板。要用故宫气质：主场给石/纸，朱红降到结构，琉璃黄只作点缀。

## 8. 颜料与工艺对面积的暗示

矿物色遮盖力强、耐久，可作 60/30：石青（蓝铜矿）、石绿（孔雀石）、朱砂（辰砂）、赭石（赤铁矿）。植物色透明、宜薄叠，默认降到 accent：花青、藤黄、胭脂、靛蓝。把胭脂红当石青那样铺满会显艳俗，因为观者预期它薄透。

罩染是中介色的传统实现：青绿若显火气，「可用淡赭罩之」。生成安静色走「原色+墨」——保持 H，同步降 C 降 L，比在 HSL 里降饱和更接近颜料，也避开塑料感。沈宗骞：「用青绿虽极重能勿没其骨为得。」以色助墨光，以墨显色彩。

金不是第 13 个色相，是光泽与角色。只走线、纹、小徽章，不作大底、不作正文底。库内含「金」的名字里，金鱼紫是酒赤，金莲花橙是橙，只有金黄、金驼、金叶黄、金盏黄、金瓜黄够金属条件。

《考工记》钟氏染羽：「三入为纁，五入为緅，七入为缁。」同一染料不同遍数各有专名，是生成同色系阶梯的本土依据。

木色、青铜、赤金都是色，必须计入层级，不能当「中性装饰」删掉。茶褐、槟榔综、淡赭归入结构色。

## 9. 场景出处

手选方案在 `references/curated.json`，算法与它们同场排序。转达给用户时把 `source` 和 `caution` 原样带上。

| 场景 | 出处一句话 | 硬约束 |
| --- | --- | --- |
| 故宫 | 汉白玉台基、朱红宫墙、明黄琉璃 | 点缀必须是朱红系（H 20°–70°），品红/紫荆红不算；主场给白或黄 |
| 青花 | 永乐甜白釉上的苏麻离青 | 只有青与白，不要第四色 |
| 水墨 | 宣纸、墨分五色、一枚朱文印 | 结构必须是深墨；点缀必须是暖红，且面积极小 |
| 敦煌 | 土红打底、石青石绿、朱砂点睛 | 允许冷暖对撞；靠浅色描边分隔 |
| 宋瓷 | 汝窑天青、龙泉粉青梅子青 | 不施彩，靠明度而非彩度分层 |
| 唐三彩 | 黄褐绿三釉交融 | 平面上给结构与点缀留出过渡 |
| 江南 | 白墙黛瓦，一枝桃花 | 点缀用淡茜红一类中彩，不要上银朱 |
| 漆器 | 黑地朱纹描金 | 金只描线；深底方案正文用纸感浅色 |
| 年画 | 杨柳青、朱仙镇，红配绿是胆气 | 允许相克，但必须一大一小 |

库内分布强烈偏暖（暖远多于冷，真中性几乎不可得）。做冷色主调时先确认候选池非空：冷灰只有十来个，月白、云峰白、远天蓝、战舰灰、鷃蓝是主力。
