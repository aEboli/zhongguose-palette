# 白话微调

用户不会说 `--mood 古朴 --pin accent=甘草黄`。他会说「太素了」「红只留印章大」「换个底其他别动」。
这张表是那些话到内部参数的映射。模型每次微调前读这里，不靠记忆。

## 三条消解规则

1. **口令优先于当前氛围。** 用户说「更艳」就往艳走，不要因为「他一开始说了素净」而打折。
2. **当前档位没有候选时，沿素艳轴升降一档，并且必须明说。** 例：雅 / 空灵下亮金候选几乎为零
   （只有龟背黄、苍黄、莱阳梨黄这类暗金），真金要到艳才有二十多个。这时候要告诉用户
   「为了给你金，整套调艳了一档」，**绝不暗中换色**。
3. **只改被点到的那一维。** 说「换个底」就只换底，钉住另外两个色。

## 映射表

| 用户说 | 内部动作 |
| --- | --- |
| 太素 / 太淡 / 不够跳 / 没劲 | 沿素艳轴 +1：雅→艳、空灵→雅、清冷→艳、古朴→浓烈 |
| 太艳 / 太花 / 太吵 / 刺眼 | 沿素艳轴 −1：艳→雅、市井→艳、浓烈→古朴 |
| 红少一点 / 红太多 | 三色不变，把点缀面积压到下限，并明说「红只在按钮和印章上」 |
| 只留一枚印章那么大 | 点缀面积锁到 2% |
| 换个底，其他别动 | `--pin secondary=<原辅色> --pin accent=<原点缀>` 重新找底 |
| 改深色 / 夜间 | `--dark`，深底从安全区取（L\*≤22 且低彩），不是把浅色方案反相 |
| 改回浅色 | 去掉 `--dark` 重跑 |
| 更喜庆 | `--scene 年画 --mood 市井`；红绿必须一大一小 |
| 冷一点 | `--mood 清冷`，或换青花 / 宋瓷 |
| 暖一点 | 氛围不变，底换成汉白玉、乳白、粉白一类暖白，避开月白（偏冷） |
| 更瓷 / 更像瓷器 | `--scene 青花` 或 `--scene 宋瓷`，只用青与白，不加第四色 |
| 更墨 / 更水墨 | `--scene 水墨 --mood 空灵`：深墨做结构，一枚朱印作点缀 |
| 加点金 | 点缀换 甘草黄 / 姜黄 / 金叶黄；金只走线不填面。素净档位无真金时按规则 2 明说 |
| 金太多 | 金限制在描边、印章、小徽章，面积锁 2% 以内 |
| 不要红 | `--pin` 换非红点缀；若场景本身以红为骨（故宫 / 年画 / 漆器），说明这个红是骨架，同时给替代方案 |
| 字看不清 | 不改三色，提高正文对比档位；若底本身不可读，说明是底的问题并给换底方案 |
| 都不喜欢 | 换整个场景大类，不做微调。问一句二选一：偏素还是偏热闹 |
| 只要两个色 | 三色降为底 + 点缀，结构用底的深色近亲 |
| 要更多色 | 不扩成等权大色板，改出 17 个派生令牌覆盖界面各处 |
| 给我代码 | 输出 CSS 变量块（亮/暗两块），或 `pick --lock` 落 `.palette/palette.css` |

## 不许做的事

- 永远不许自己调 hex。要库外的色就跑 `palette.py snap "#xxxxxx"` 吸附到库内最近具名色。
- 不许因为「分数不够」就悄悄换掉用户钉死的色。用户钉住就是他的决定。
- 不许把被否决的方向静默替换。挡回去的时候说一句原因（「这个蓝配紫是传统里点名的死局」）。
